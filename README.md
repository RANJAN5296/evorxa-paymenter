## 📋 What Is This?

Evorxa Paymenter is a free tool that lets you **resell Evorxa VPS and VDS cloud servers** to your own customers. It works as an add-on for Paymenter, a popular hosting billing panel. With this extension, you can:

- **Sell cloud servers automatically** – no manual setup needed
- **Give customers a control panel** – they can manage their own servers
- **Add your own profit margin** – set your own prices on top of Evorxa's rates

Think of it like this: Evorxa provides the actual server hardware and network. This tool handles everything else – billing, management, and customer access – so you can focus on growing your business.

## ✨ Key Features

### 🖥️ Automatic Server Provisioning
When a customer buys a server, it's created instantly. No waiting, no manual work. The system talks directly to Evorxa's API and sets everything up.

Your customers see **your brand**, not Evorxa's. They get a professional control panel where they can:

## 📚 How It Works (Simple Explanation)

1. **Your customer** visits your website and orders a server.
2. **Paymenter** processes the payment and sends a message to this extension.
3. **Evorxa Paymenter** calls Evorxa's API to create the server.
4. **The server** is instantly provisioned with your customer's chosen specs.
5. **Your customer** logs into their control panel and manages everything themselves.
6. **You** earn the difference between Evorxa's price and your price – automatically, every month.

It's that simple. No emails, no phone calls, no manual work.

## 🛠️ Troubleshooting Tips

**Problem: "Connection Failed" when connecting to Paymenter**
- Make sure your Paymenter panel is online and the URL is correct
- Double-check that your API key is valid and has admin permissions

**Problem: Plans don't appear after import**
- Refresh the page in Paymenter
- Make sure you're logged in as an admin

**Problem: Server provisioning takes too long**
- Check your internet connection
- Ensure your Evorxa account has sufficient funds or credit

**Problem: Application won't start**
- Restart your computer
- Run the installer again (it will repair the installation)
